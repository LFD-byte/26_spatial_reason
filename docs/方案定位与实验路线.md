# 空间嵌入 + LLM 推理:方案定位与实验路线

> 状态:草案 v0.2(2026-11-12)· 目标会议:ACL 2027
> 本文档记录方案的定位、模型设计、训练与评测路线,后续讨论和修改直接在此更新。
> v0.2:根据第一轮实验结果调整了任务设计和编码器选择,见第 11 节;第 6 节编码器部分随之修改。

---

## 1. 一句话定位

LLMiniST(ACL 2025)证明了 LLM 能做空间 niche 识别,但它主要依赖文本先验,零样本不稳定;BioReason(NeurIPS 2025)证明了把基础模型嵌入接进 LLM、再用强化学习训练推理,在 DNA 上可行。**本工作把后者迁移到空间转录组,用来解决前者暴露出的问题。**

技术路线上是"BioReason 的空间版";从 LLMiniST 借的是任务设定、数据集和评测方法。

## 2. 动机:要解决的问题

1. **文本路线丢信息、靠先验。**
   - LLMiniST 把细胞类型名换成抽象标签后,零样本 NMI 从 0.72 跌到 0.19;MERFISH 上零样本 NMI 只有 0.068。
   - Cell-Lens:CD8A 只出现在 7–9% 的 CD8 T 细胞 cell sentence 中,而蛋白层面 93–98% 的细胞表达它。
   - 文本输入还依赖上游的细胞注释和反卷积,误差层层传递。
2. **空间基础模型缺少生物学先验,不会多步推理。**
   - OCellus 去掉 LLM 基因嵌入后,Pearson 从 0.945 跌到 0.06,说明外部知识贡献巨大。
3. **智能体的瓶颈在科学判断,不在写代码。**
   - SpatialBench-Long:最好的组合也只通过 11%;75 条失败中只有 3 条是运行错误,另有 6 条是"用先验代替数据"作答。
4. **"嵌入直接输入 LLM + RL 推理"在空间方向基本空白。**
   - 现有单细胞推理工作(Cell-o1、CellDuality、C2S-Scale)都走 cell sentence 路线。

## 3. LLM 要带来的价值(论文卖点)

只做 niche 分类时,"编码器 + 线性头"可能就够了。LLM 真正有优势、线性头做不到的地方有三个:

- **开放词表**:用文字描述新的 niche 类别,不重新训练就能识别(如三级淋巴结构、肿瘤-基质交界)。
- **跨组织、跨标签体系迁移**:换一套注释体系也能用。
- **可解释、忠实的推理**:说明判断依据是哪些细胞和基因,并且这些依据在数据里真实存在。

评测围绕这三点设计。对 ACL 而言,推理的忠实性(faithfulness)应作为方法亮点,不要只当附属实验。

## 4. 与相关工作的关系

| 方面 | BioReason | 本方案 | LLMiniST |
|---|---|---|---|
| LLM 的输入 | DNA 基础模型嵌入,作为 token 输入 | 空间基础模型嵌入,作为 token 输入 | 文本 prompt |
| 编码器 | Evo2 / NT | Novae / Nicheformer(冻结) | 无,依赖上游注释与反卷积 |
| 投影层 | 有 | 有 | 无 |
| LLM | 开源 Qwen3 + 微调 | 开源 Qwen3 + LoRA | 闭源 GPT-4o / Gemini |
| 训练 | SFT → RL | 对齐 → SFT → GRPO | 零样本 / 标准微调 |
| 输出 | 推理链 + 答案 | 推理链 + 答案 + 证据 | 主要是标签 |

**借鉴关系:**
- **BioReason**:整体架构与训练流程,代码可作为骨架。
- **LLMiniST**:niche 识别任务;DLPFC、MERFISH、STARmap 数据集;两阶段原型修正;抽象标签消融;作为文本路线的主要对照。
- **NicheAgent**:原型推断加受约束 LLM 修正低置信度细胞,作为对照或可借鉴模块。
- **Cell-o1、CellDuality**:单细胞上的 SFT + GRPO 训练细节和奖励设计。

**本方案相对 BioReason 新增的部分:**
1. 邻域 token 化:目标细胞加 k 个邻居,带相对坐标编码;区域级任务先池化。
2. 嵌入-描述对齐阶段(阶段 0)。
3. 证据奖励,以及推理忠实性评测。

## 6. 模型结构

1. **细胞编码器**(v0.2 修改,依据见第 11 节)
   - 原计划首选 Novae(冻结)。第一轮实验中它在线性探针、无监督域划分和 stage 1 上都不如 PCA,已降为对照。
   - 现用 PCA(每个数据集单独拟合),作为单数据集任务的基线编码器。
   - 主编码器候选是方案 B:基因集合编码器,基因嵌入来自基因名在 LLM 中的文本表示,不绑定基因 panel,与投影层端到端训练。它是唯一既能跨 panel、又在数据上不弱于 PCA 的候选,需要等结果确认。
   - 对照编码器:Novae(零样本、微调、从头训练三种变体)、Nicheformer。
2. **输入单元**
   - 目标细胞加 k 个邻居(初始 k = 32–64),每个细胞一个嵌入 token,加相对坐标编码。
   - 区域级任务先在微区域内池化,避免 token 数爆炸。
3. **投影层**:两层 MLP,映射到 LLM 隐藏维度。
4. **LLM**:Qwen3-4B(先调通)→ 8B,LoRA 微调。
5. **可选混合输入**:prompt 中附 top marker 基因文本;这一组同时作为消融。

## 7. 训练流程

**阶段 0:对齐投影层**
- 冻结 LLM,只训练投影层。
- 任务:"看嵌入写描述"。描述从数据自动生成,例如"邻域中 45% 为 T 细胞、20% 为成纤维细胞,CXCL13、CCL19 高表达",无需人工标注。

**阶段 1:SFT 冷启动**
- 前沿 LLM 读取文本形式的数据和真值标签,生成推理轨迹;学生模型看到的是嵌入,学习同样的轨迹。
- 过滤:只保留结论正确、而且引用的细胞或基因确实在输入中富集的轨迹。

**阶段 2:GRPO 强化学习**

奖励由多项组成,互相制约,防止 CellRFT 式的奖励作弊:
- 标签正确;
- 格式合规;
- **证据奖励**:推理中提到的细胞类型或基因必须在该邻域里真实富集,否则扣分,专门针对"用先验代替数据";
- (可选)空间一致性:相邻区域的预测不应剧烈跳变。

**推理阶段(可选)**:借用 LLMiniST 的两阶段原型修正,用于跨重复、跨个体迁移。

## 8. 评测设计

### 8.1 对照组

1. 传统空间聚类:BASS、GraphST、STAGATE、CellCharter。
2. **同一编码器 + 线性头 / kNN**:检验 LLM 有没有带来增益(最关键)。
3. 朴素 PCA 编码器 + 线性头。
4. LLMiniST(零样本、微调、两阶段)、NicheAgent。
5. **同一个 Qwen 只用文本 prompt 微调**:与本方法只差"有没有嵌入",是最公平的比较;ACL 审稿人一定会问。

### 8.2 消融实验

- 嵌入换成随机向量,或打乱邻域空间位置:性能应明显下降,否则说明 LLM 没在用空间信息。
- **抽象标签**:细胞类型和 niche 名称换成无语义标签。本方法应比文本路线稳得多,这是"在读数据而不是靠先验"的核心证据。
- 分别去掉阶段 0、阶段 1、阶段 2。
- 编码器:Novae vs Nicheformer vs PCA。
- 邻居数 k。
- 有无混合文本输入。

### 8.3 指标

- **标签任务**:NMI、ARI、准确率;分别报告跨重复、跨个体、跨平台三种划分。
- **开放词表**:未见过的 niche 类别仅给文字描述时的识别率。
- **推理忠实性**:自动检查引用证据是否真实存在、是否富集;抽样请领域专家盲评。
- **泄漏检查**:在 2025 年后公开的数据上单独报告。

## 9. 阶段安排与停止条件

| 阶段 | 内容 | 时长(估计) | 继续或调整的判断 |
|---|---|---|---|
| 1 | 跑通所有基线;编码器 + 线性头 vs PCA + 线性头 | 2–3 周 | 编码器不比 PCA 好 → 换编码器或换数据集 |
| 2 | 阶段 0 + 阶段 1;对比纯文本 Qwen | 3–4 周 | 嵌入版至少与文本版持平,且在抽象标签设置下更稳 |
| 3 | GRPO + 证据奖励 | 3–4 周 | 提升不能只来自奖励作弊(看多指标与证据检查) |
| 4 | 开放词表、跨平台泛化、忠实性评测、写作 | — | — |

**算力估计**:4B + LoRA 的 SFT 单机 8 卡即可;GRPO 每个样本多次采样,开销是 SFT 的数倍,先在 4B 上调通流程。

**最优先做的两组对照**:编码器 + 线性头;同一个 LLM 只用文本微调。它们决定论文的故事能否成立。

## 10. 风险与应对

| 风险 | 应对 |
|---|---|
| 空间编码器本身不可靠(SAFFRON:多数模型没学到多尺度结构) | 阶段 1 先验证;准备多个编码器和 PCA 对照 |
| 增益其实来自 LLM 文本先验 | 抽象标签消融、随机嵌入消融、纯文本 Qwen 对照 |
| 邻域 token 数过多 | 微区域池化、分层编码 |
| 可验证奖励稀缺,或出现奖励作弊 | 多项奖励互相制约;监控多个指标 |
| 测试数据泄漏(LLM 背诵已发表结论) | 用 2025 年后公开的数据单独评测 |
| 推理结果不可复现 | 报告多次运行的方差与一致性 |

## 11. 第一轮实验结论与方向调整(2026-11-12)

### 11.1 已有结果

数据集:CosMx NSCLC、MERFISH 下丘脑、STARmap。任务是 LLMiniST 的域识别:给定候选标签,判断中心细胞所在 niche 属于哪个组织域。LLM 为 Qwen3-4B,输入 33 个细胞 token(中心细胞 + 32 个近邻)。

**表 1 · 线性探针准确率**(中心细胞表示与邻域平均表示拼接,逻辑回归;不经过 LLM)

| 编码器 | CosMx | MERFISH | STARmap |
|---|---|---|---|
| PCA | **0.43** | **0.82** | **0.87** |
| Novae 零样本 | 0.35 | 0.43 | 0.69 |
| Novae 微调 | 0.36 | 0.50 | 0.69 |
| Novae 从头训练 | 未完成(训练卡住) | 0.69 | 0.80 |
| Nicheformer(仅 CosMx) | 0.41 | — | — |

**表 2 · stage 1 全量验证集准确率**(best checkpoint)

| | CosMx | MERFISH | STARmap | 总体 | 证据有效率 |
|---|---|---|---|---|---|
| PCA + LLM | 0.383 | 0.656 | 0.825 | 0.565 | 0.528 |
| PCA + LLM,打乱嵌入 | 0.264 | 0.450 | 0.682 | 0.409 | — |
| Novae + LLM | 0.269 | 0.453 | 0.766 | 0.428 | 0.472 |
| Qwen3-32B 读标注统计(纯文本) | 0.433 | 0.253 | 0.812 | — | — |

- 纯文本基线读的是**用人工标注算出的**邻域细胞类型组成和富集基因,相当于给了它完美的上游注释,不是"只靠先验"。
- stage 0 中,真实嵌入与打乱嵌入的 loss 差距:PCA 0.233,Novae 0.121。

**表 3 · 无监督空间域划分 ARI**(全部切片平均,k 取真实域数;`scripts/10_domain_clustering.py`)

| 方法 | STARmap | MERFISH | CosMx |
|---|---|---|---|
| PCA 邻域平均 + k-means | **0.39** | **0.38** | **0.23** |
| Novae 自带域划分 | 0.28 | 0.14 | 0.22 |
| Novae 表示 + k-means | 0.26 | 0.17 | 0.17 |
| Novae 微调 / 从头训练(最好的一种) | ≤ 0.10 | ≤ 0.13 | ≤ 0.16 |
| 单细胞 PCA(不含空间) | 0.18 | 0.12 | 0.11 |
| 真实细胞类型组成(oracle) | 0.80 | 0.17 | 0.41 |

### 11.2 原因分析

1. **Novae 落后的原因在编码器本身,不在 LLM 架构。**
   - 不经过 LLM 的两项测试(有监督探针、无监督域划分)中,Novae 都落后于 PCA。
   - 在 Novae 的设计目标"域划分"上,它在两个小鼠数据集也输给 PCA 邻域平均,只在 CosMx 上持平。CosMx 是人类数据,最接近 Novae 的预训练分布。
   - Novae 接进 LLM 后,stage 1 准确率(0.428)和打乱嵌入的 PCA(0.409)接近,说明 LLM 从 Novae 嵌入里几乎没读到额外信息。
2. **训练目标不匹配。**
   - Novae 的目标让表示在空间上平滑、按组织域聚类,会丢掉细胞自身的身份信息,而当前任务恰好依赖这部分信息。
   - 在本数据上微调或从头训练 Novae,探针准确率上升,但域划分能力几乎消失:两种能力此消彼长。
   - 从头训练仍不如 PCA,说明这些数据的规模不够支撑 Novae 的自监督目标。
3. **数据集带来的干扰**(会放大 Novae 的劣势,但单独解释不了它的落后)
   - STARmap 坐标是像素单位(相邻细胞距离中位数 284),影响 Novae 构建邻域图,**尚未排除**。引用 STARmap 上的 Novae 数字时需注明。
   - MERFISH 的域不由细胞类型组成决定(oracle 只有 0.17),域边界更多取决于表达梯度。
4. **LLM 架构本身的瓶颈。**
   - 同一份 PCA 嵌入,经过 LLM 后比线性探针低:MERFISH 0.656 对 0.82,CosMx 0.383 对 0.43。
   - 打乱嵌入后准确率明显下降,说明 LLM 确实在读嵌入,只是没有读全。方案 B 针对的就是这一点。

### 11.3 核心问题:现任务体现不出 LLM 的价值

LLMiniST 的域识别是**封闭集分类**:候选标签固定,每个数据集都有训练标签。在这种设定下,一个逻辑回归在三个数据集上都赢过 LLM(表 1 与表 2)。无论换哪个编码器,这个结论都不变。第 3 节已经预见到这个问题;第一轮结果说明,必须让主实验落在线性头做不到的设定上。

**原则:按"LLM 能做而线性头做不到"来设计任务,不按"让某个编码器赢"来设计。** 后一种做法审稿人一眼就能看出来。

### 11.4 任务重新设计(按优先级)

| 编号 | 任务 | 线性头为什么做不到 | 训练轨迹 | 主要对照 |
|---|---|---|---|---|
| T0 | LLMiniST 原任务(保留) | 线性头能做,作为可比性锚点 | 复用现有轨迹 | 线性探针、LLMiniST 已发表结果 |
| T1 | **跨数据集零样本域识别**:在若干数据集上训练,在没见过的数据集和标签体系上测试,候选标签以文字给出 | 测试集没有训练标签,无法拟合分类头 | **复用现有训练轨迹**,只需构建新测试集 | 纯文本 Qwen 读标注统计(LLMiniST 式);无监督聚类后用 LLM 命名(NicheAgent 式);Novae 零样本域划分 |
| T3 | **证据忠实性**:证据有效率升为主要指标;加反事实检验(从邻域中去掉某类富集细胞的 token,看回答和证据是否随之改变) | 线性头不给出依据 | 不需要新轨迹,是评测方案 | 打乱嵌入、纯文本 Qwen |
| T2 | **开放词表**:训练时每个数据集留出一个域类别,测试时只给它的文字描述 | 留出类别没有训练样本 | 需要重新生成去掉留出类别的轨迹 | 纯文本 Qwen;按标签名做零样本匹配 |
| T4 | **关系推理**:比较两个 niche、判断是否位于域边界、指出区分两个域的细胞类型;答案由标注自动生成,可核验 | 需要同时读多组 token,不是单个向量分类 | 需要新教师轨迹(Qwen3-32B) | 线性头(对能化成分类的子问题)、纯文本 Qwen |

- **T1 最先做**:训练部分完全复用,成本最低,而且最直接回答"为什么用 LLM"。
  - 候选测试集:DLPFC(Visium,人类,斑点级分辨率,已在流程中),以及一份 2025 年后公开的单细胞分辨率数据,用来防泄漏。
  - 注意:DLPFC 和训练集跨物种、跨平台、跨分辨率,难度高;最好再加一个同平台留出数据集,作为难度较低的一档。
- 抽象标签消融(8.2 节)可以直接套在 T1 上。
- T2 和 T4 需要重新生成教师轨迹,估计各需 1–2 天 GPU 时间,放在 T1 和 T3 之后。

### 11.5 编码器选择标准

1. **编码器是受控变量,不是论文卖点。** 主编码器按事先固定的标准选:训练与验证切片上的探针准确率,加上 stage 0 中真实嵌入与打乱嵌入的 loss 差距。**看到 T1 测试结果之前定下来**,不按测试结果换编码器。
2. **T1 要求编码器能跨基因 panel。**
   - PCA 每个数据集单独拟合,各数据集的维度含义不同,不能直接用于跨数据集零样本。它保留为 T0 的基线和单数据集上限参照。
   - 能跨 panel 的候选只有方案 B(基因嵌入来自基因名)和 Novae。T1 也正好是 Novae 的设计场景,对它更公平。
3. **按任务需要的信息选编码器。** 细胞层面的任务用表达类编码器(PCA、方案 B,以后可加 scGPT)。组织域层面的任务把 Novae 作为对照;CosMx 上它和 PCA 持平。
4. **"零样本空间基础模型在细胞级邻域推理上不如简单表达表示"作为分析结论写进论文**(表 1–3),不回避。
